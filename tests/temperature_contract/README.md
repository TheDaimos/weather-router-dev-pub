# Temperature V2 public contract examples

Explicitly synthetic fixtures generated by the locally tested WR temperature implementation. No private source, original weather files, coordinates from an installation, credentials, diagnostic export or private history is copied. The tests verify the delivered public numerical contract and selected stencil outputs. They do not execute the private backend or constitute an HA/device/scientific campaign. The canonical DRA source remains the private deploy/dev branch.

Private implementation and test-file SHA256 attestations and the exact implementation commit are recorded in the release report. Public files are limited to this directory and the scoped workflow; main and existing OPERA workflows remain unchanged.
